## 报价单之外，这些费用别漏算

按带宽算出的月费是大头，但一笔专线的完整开销还包括几项容易被忽略的部分：

- **CPE设备租用**：连接企业网络与专线的硬件，费用通常包含在服务费里，但要确认清楚，别等账单来了才发现单独计费
- **安装费**：一次性的，涉及设备配置和网络调试
- **维护和支持费**：定期维护、故障排除、技术支持
- **SLA等级差价**：可用性、延迟、丢包承诺越高的SLA，费用越高，高级别SLA往往要额外加钱

比费用结构更要紧的是合同条款。有些方案表面月费便宜，但流量上限、带宽保证、超量之后怎么收费写得含糊，事后账单可能让人吃惊。签合同前把这几条逐项过一遍，比在月费上砍价几百块有价值得多。

## 为什么同样是10M，报价能差出几倍？

四个变量决定你拿到的报价单长什么样。

**落地点和距离**排第一。香港是跨境线路的前哨，价格相对便宜；日本、韩国、新加坡次之；美国和欧洲方向最贵。两地的地理距离越远，建设成本越高，这部分成本一定会转嫁到报价里。

**带宽**是最核心的计费依据，需求越高费用越高，这一项几乎没有谈判空间。

**SLA等级**看业务性质。金融机构、在线游戏公司这类对稳定性极其敏感的买家，会为更高的可用性、延迟和丢包承诺付费；如果你的业务容忍度高，选低一档的SLA能省下不少。

**安全配置**也会拉开价差。带数据加密、防火墙等功能的方案，报价更高，但合规要求严格的行业躲不开这一项。

另外，不同服务商的技术水平和服务质量本身就不一样，报价体系也不同，多拿几家对比是基本操作。

## 办运营商专线之前，先过一遍合规门槛

这一块是大部分介绍文章直接跳过的，但实际办理时绕不开。

三大运营商的跨境专线通常按“组网项目”来批，典型拓扑是：公司本地站点 → 国内运营商机房 → 境外运营商机房 → 公司境外站点。也就是说，运营商默认你两端都有实体站点。大多数公司没有境外站点，这种情况可以用云站点代替，办理前先跟运营商确认清楚。

还有一道手续：办理时通常需要填写表格，承诺线路只用于哪些用途、不访问哪些内容。正规做法是与运营商直签。市面上有些小运营商不要求签这些，价格也更低，但那意味着不合规，出了问题没有保障。如果你的场景确实需要合规专线，这些流程本身就是成本的一部分，排期时把审批时间也算进去。

## 几个高频问题

**海外专线和普通国际带宽有什么区别？**
专线是专用带宽加SLA保障，可用性、延迟、丢包率写进合同；普通国际线路是共享带宽，高峰期拥堵时没有任何承诺。两者价格差的就是这个保障。

**10M专线够用吗？**
看用途。远程办公、网页类业务一般够用；涉及大量文件传输、视频会议密集、实时数据同步的场景，先摸清日常用量再定带宽，拍脑袋选只会多花钱或者不够用。

**专线能按月签吗？**
运营商的企业专线一般按年签合同，报价也按年谈。想按月灵活付费，只有VPS、云主机这类方案能做到，这也是个人用户更合适的选项。

**香港线路为什么便宜？**
距离近，是跨境流量的前哨站，建设成本低于欧美方向，同样带宽的报价自然更低。
